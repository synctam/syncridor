インストールガイド

Syncridorは、Python 3.8以上とpygameライブラリを使用して動作します。このガイドでは、各オペレーティングシステムでの詳細なセットアップ方法を説明します。

⚡ クイックスタート

最短でゲームを開始する方法

# 1. Pythonが既にインストールされている場合
pip install pygame

# 2. ゲームファイルをダウンロード
git clone https://github.com/synctam/syncridor.git
cd syncridor

# 3. ゲーム開始
python syncridor_game.py

🪟 Windows でのインストール

方法1: Python.org からのインストール（推奨）

ステップ1: Python のインストール

  1. Python公式サイトから最新版をダウンロード
  2. インストーラーを実行
  3. 重要: 「Add Python to PATH」にチェックを入れる
  4. 「Install Now」をクリック

⚠️ インストール時の注意点

  • 「Add Python to PATH」のチェックを忘れずに！
  • 管理者権限でインストーラーを実行することを推奨
  • Python 3.8以上のバージョンを選択

ステップ2: インストール確認

コマンドプロンプト（cmd）またはPowerShellを開いて以下を実行：

python --version
pip --version

ステップ3: pygame のインストール

pip install pygame

ステップ4: Syncridor のダウンロードと実行

# Git を使用する場合
git clone https://github.com/synctam/syncridor.git
cd syncridor

# または ZIP ファイルをダウンロードして展開
# その後、フォルダ内で：
python syncridor_game.py

方法2: Microsoft Store からのインストール

  1. Microsoft Store を開く
  2. 「Python」で検索
  3. 「Python 3.11」（または最新版）をインストール
  4. 上記のステップ3以降を実行

方法3: PyCharm を使用した開発環境

  1. PyCharm Community Editionをダウンロード・インストール
  2. 「New Project」→「Pure Python」を選択
  3. プロジェクト設定で仮想環境を作成
  4. Terminal で pip install pygame を実行
  5. Syncridor のソースコードをプロジェクトにコピー
  6. syncridor_game.py を右クリック → 「Run」

🍎 macOS でのインストール

方法1: Homebrew を使用（推奨）

ステップ1: Homebrew のインストール

Terminal を開いて以下を実行：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

ステップ2: Python のインストール

brew install python

ステップ3: pygame のインストール

pip3 install pygame

ステップ4: Syncridor の実行

git clone https://github.com/synctam/syncridor.git
cd syncridor
python3 syncridor_game.py

方法2: 公式インストーラー使用

  1. Python公式サイトからmacOS用インストーラーをダウンロード
  2. インストーラーを実行
  3. Terminal で pip コマンドを使用してpygameをインストール

⚠️ macOS での注意事項

  • macOS 10.14 (Mojave) 以降が必要
  • システム標準のPython 2.7ではなく、Python 3を使用
  • Xcodeコマンドラインツールが必要な場合があります：xcode-select --install

🐧 Linux でのインストール

Ubuntu/Debian 系

# システムアップデート
sudo apt update && sudo apt upgrade

# Python と pip のインストール
sudo apt install python3 python3-pip git

# pygame のインストール
pip3 install pygame

# Syncridor の取得と実行
git clone https://github.com/synctam/syncridor.git
cd syncridor
python3 syncridor_game.py

Red Hat/CentOS/Fedora 系

# パッケージマネージャーのアップデート
sudo dnf update  # または sudo yum update

# Python と pip のインストール
sudo dnf install python3 python3-pip git

# pygame のインストール
pip3 install pygame

# Syncridor の取得と実行
git clone https://github.com/synctam/syncridor.git
cd syncridor
python3 syncridor_game.py

Arch Linux

# システムアップデート
sudo pacman -Syu

# Python と pip のインストール
sudo pacman -S python python-pip git

# pygame のインストール
pip install pygame

# Syncridor の取得と実行
git clone https://github.com/synctam/syncridor.git
cd syncridor
python syncridor_game.py

🔧 仮想環境を使用したインストール（推奨）

プロジェクトごとに独立したPython環境を作成することで、依存関係の競合を避けることができます。

仮想環境の作成と使用

# 1. プロジェクトディレクトリの作成
mkdir syncridor-project
cd syncridor-project

# 2. 仮想環境の作成
python -m venv venv

# 3. 仮想環境のアクティベート
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. pygame のインストール
pip install pygame

# 5. Syncridor のダウンロード
git clone https://github.com/synctam/syncridor.git
cd syncridor

# 6. ゲームの実行
python syncridor_game.py

# 7. 作業終了時は仮想環境を非アクティブ化
deactivate

✅ 仮想環境のメリット

  • 分離性: プロジェクトごとに独立した環境
  • 再現性: 同じ環境を他のマシンで再現可能
  • 安全性: システムのPython環境への影響なし
  • 管理性: 不要になった場合は簡単に削除可能

🚨 トラブルシューティング

よくある問題と解決方法

問題1: 「python: command not found」エラー

原因: PythonがPATHに追加されていない、またはインストールされていない

解決方法:

  • Pythonが正しくインストールされているか確認
  • WindowsでPATHにPythonを追加
  • macOS/LinuxでPython3として実行: python3 syncridor_game.py

問題2: 「No module named 'pygame'」エラー

原因: pygameがインストールされていない

解決方法:

# 再インストール
pip install pygame

# または特定バージョンの指定
pip install pygame==2.6.0

# macOS/Linux の場合
pip3 install pygame

問題3: ゲーム画面が表示されない

原因: ディスプレイドライバーまたはpygameの問題

解決方法:

  • グラフィックドライバーの更新
  • pygame の再インストール
  • コマンドラインで詳細エラーを確認

問題4: Git が利用できない

解決方法: Gitを使わない場合

  1. GitHubページにアクセス
  2. 「Code」→「Download ZIP」をクリック
  3. ZIPファイルを展開
  4. 展開したフォルダでゲームを実行

エラーログの確認方法

# 詳細なエラー情報を表示
python syncridor_game.py 2>&1 | tee error.log

# Pythonの環境情報を確認
python -m pip list
python -c "import pygame; print(pygame.version.ver)"

🔄 アップデート方法

Syncridor の更新

# Git を使用している場合
cd syncridor
git pull origin main

# ZIP でダウンロードした場合
# 新しいバージョンを再度ダウンロードして置き換え

pygame の更新

# 最新版に更新

# 特定バージョンにアップデート
pip install pygame==2.6.0
