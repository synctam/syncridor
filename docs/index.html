Syncridor ドキュメント

Syncridorは、クラシックな戦略ボードゲームにインスパイアされた独立したオープンソース実装です。距離ベースの戦略を持つ3種類のAIが実装されており、人間対AI、AI対AIの対戦が可能です。

🚀 クイックスタート

1. インストール

# 1. リポジトリをクローン
git clone https://github.com/synctam/syncridor.git
cd syncridor

# 2. 仮想環境を作成・アクティベート
python -m venv venv
source venv/bin/activate  # Linux/Mac
# または
venv\Scripts\activate     # Windows

# 3. 依存関係をインストール
pip install pygame

# 4. ゲームを実行
python syncridor_game.py

2. ゲームの遊び方

  • 左クリック: プレイヤーを移動
  • 右クリック: 壁を配置
  • スペースキー: 壁の向き切り替え（水平/垂直）
  • R: ゲームリスタート
  • M: メインメニューに戻る

3. ゲームモード

  • 1キー: 人間 vs 人間
  • 2キー: 人間 vs AI
  • 3キー: AI vs AI（推奨：AI戦略を観察）

🎯 ゲームの特徴

✨ 主な特徴

  • 3種類のAI戦略: 攻撃的、守備的、バランス型
  • 距離ベースアルゴリズム: 最短経路計算による戦略的判断
  • 視覚的な壁表示: プレイヤー別の色分け（青・赤）
  • リアルタイムAI対戦: AI vs AIで戦略を観察可能
  • 包括的テスト: 25のテストケースで品質保証
