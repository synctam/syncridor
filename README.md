# Syncridor Game - AI戦略解説

## 概要

このプロジェクトは、Pygameを使用して開発されたSyncridorボードゲームの実装です。特に、距離ベースの戦略を持つ3種類のAIが実装されており、人間対AI、AI対AIの対戦が可能です。

## ゲームの基本ルール

### Syncridorとは
Syncridorは2人用の戦略ボードゲームで、9×9のボードで相手のゴールラインに先に到達することを目指します。クラシックな戦略ボードゲームにインスパイアされた独立した実装です。

### 基本ルール
1. **ボード**: 9×9のグリッド
2. **開始位置**: プレイヤー1（青）は下側中央(8,4)、プレイヤー2（赤）は上側中央(0,4)
3. **ゴール**: プレイヤー1は上端(row=0)、プレイヤー2は下端(row=8)に到達
4. **壁**: 各プレイヤーは10個の壁を持ち、相手の進路を妨害可能
5. **移動**: 隣接するマスに移動、または相手プレイヤーを飛び越え可能

### 壁設置の制約
- 壁は2マス分の長さ（水平または垂直）
- 既存の壁と重複・交差不可
- 両プレイヤーがゴールに到達できるパスを残す必要がある

- `Player`: PLAYER1, PLAYER2
- `AIStrategy`: AGGRESSIVE, DEFENSIVE, BALANCED

## AI戦略の詳細解説

### 1. 基本アルゴリズム

#### 最短経路探索
```python
def get_shortest_path(self, start_pos, goal_row, walls=None):
    """BFS（幅優先探索）でゴールまでの最短経路を計算"""
```
- **アルゴリズム**: BFS（Breadth-First Search）
- **目的**: 現在位置からゴールまでの最短距離と経路を計算
- **考慮要素**: 配置済みの壁による経路の遮断

#### 戦略的壁配置
```python
def find_strategic_wall(self):
    """全ての可能な壁位置を評価し、最適な配置を決定"""
```
- **評価基準**: 
  - 相手の距離延長効果: `opponent_delay × 2`
  - 自分の距離への影響: `current_delay`（減点）
  - 相手が近い場合の追加ボーナス: `opponent_delay × 1.5`

### 2. AI戦略タイプ

#### A. 攻撃的AI (AGGRESSIVE)
**特徴**: 相手の妨害を最優先

**壁配置確率**:
- 不利/互角（距離差 ≥ 0）: **60%**
- 有利（距離差 < 0）: **20%**

**行動パターン**:
1. 距離差を計算
2. 確率に基づき壁配置を検討
3. 戦略的壁の配置実行
4. 最短経路に沿った移動

```python
def ai_make_move_aggressive(self):
    # 距離差に基づく戦略判断
    distance_diff = current_distance - opponent_distance
    wall_probability = 0.6 if distance_diff >= 0 else 0.2
```

#### B. 守備的AI (DEFENSIVE)
**特徴**: 自分のゴール到達を最優先

**壁配置確率**:
- 2歩以上の劣勢: **40%**
- 1歩の劣勢: **20%**
- 有利な状況: **5%**

**行動パターン**:
1. 主に最短経路での移動を優先
2. 明確な劣勢時のみ防御的壁配置
3. 壁の温存戦略

```python
def ai_make_move_defensive(self):
    if distance_diff >= 2:
        wall_probability = 0.4
    elif distance_diff == 1:
        wall_probability = 0.2
    else:
        wall_probability = 0.05
```

#### C. バランス型AI (BALANCED)
**特徴**: 状況に応じた適応的戦略

**壁配置確率**:
- 不利（距離差 ≥ 1）: **45%**
- 互角（距離差 = 0）: **30%**
- 有利（距離差 < 0）: **15%**

**行動パターン**:
1. 距離差に比例した壁配置確率
2. 中庸な戦略バランス
3. 状況適応型の意思決定

### 3. 意思決定フロー

```
1. 現在の盤面状態を分析
   ├─ 自分の最短距離計算
   ├─ 相手の最短距離計算
   └─ 距離差の算出

2. 戦略に基づく行動選択
   ├─ 壁配置確率の計算
   ├─ 確率的な壁配置判定
   └─ 戦略的壁位置の探索

3. 行動実行
   ├─ 壁配置成功 → ターン終了
   ├─ 壁配置失敗 → 移動へ
   └─ 最短経路に沿った移動
```

### 4. 戦略的考察

#### 攻撃的AI vs 守備的AI
- **攻撃的AI**: 早期から壁で相手を牽制、ゲーム時間を延長
- **守備的AI**: 直進重視、壁の無駄遣いを避ける
- **結果**: 守備的AIが効率的なゴール到達で勝利する傾向

#### 最適戦略
1. **序盤**: 相手の主要経路を把握
2. **中盤**: 距離差に応じた壁配置
3. **終盤**: 壁の残数を考慮した資源管理

## 操作方法

### ゲーム開始
```bash
python syncridor_game.py
```

### テスト実行
```bash
# 全テストの実行
python test_syncridor.py

source venv/bin/activate  # Linux/Mac

python test_syncridor.py
```

### ゲームモード選択
- **1キー**: 人間 vs 人間
- **2キー**: 人間 vs AI
- **3キー**: AI vs AI

### ゲーム中の操作
- **左クリック**: プレイヤー移動
- **右クリック**: 壁配置

- **Rキー**: ゲームリスタート
- **Mキー**: メインメニューに戻る
